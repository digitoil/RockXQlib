RockXQlib 系统总结

功能、目标与当前状态  ·  生成日期 2026-10-07  ·  代码基线 be4dbea 之后

一、系统定位

RockXQlib 是一个把 qlib 量化研究流程「图形化」的桌面工具 —— 用拖节点代替写 Python， 把「数据 → 特征 → 数据集 → 模型 → 策略 → 回测」整条流水线串起来跑通，并直接看到绩效结果。

二、系统目标

目标具体含义
把 qlib 从代码库变成可操作的工具不用写 Python，通过节点画布 + 属性编辑器搭出一条完整的量化策略流水线
让链路真跑通、结果可信宁可明确失败也不伪造数据（早期 3 处假信号已全部删除）；配置必须真的生效，不允许「配了不生效」
让结果可读回测产出年化收益、最大回撤、夏普、超额收益、换手率，并渲染资金曲线与回撤曲线
核心自包含、扩展可插拔核心只依赖 qlib + PySide6 + pandas/numpy，不背 AI、数据库等重依赖；扩展改一行配置即可启停

三、系统分层全貌

系统分为四层，核心特征是依赖单向：上层依赖下层，下层不反向引用。这是「核心干净、扩展可插拔」的基础。

五、功能清单

交互层  launch_gui_complete_integration.py，2,398 行

  • 节点画布 —— 拖拽创建、端口连线；执行时节点高亮（橙=运行中／绿=成功／红=失败），下次运行自动还原
  • 属性编辑器 —— 修改参数的唯一生效入口（右侧「属性编辑器」页签）
  • 回测结果面板 —— 6 张指标卡片 + 资金曲线／回撤曲线／日收益图；3 张图共享一份 plotly.js，HTML 体积 13.95 MB → 4.70 MB
  • 菜单栏 —— 文件 / 编辑 / 视图 / 工作流 / 帮助

执行层

  • 一键运行（workflow_runner.py）—— 按真实端口连线做 Kahn 拓扑排序；兼容新旧两套节点契约（execute() 与 execute(inputs)）；运行前预检（无连线／成环／缺 execute）
  • 工作流序列化（workflow_schema.py）—— 节点图 ↔ 简洁 JSON、结构校验、生成给 LLM 的节点说明书
  • 统一节点管理（unified_node_manager.py）—— 按配置加载节点系统，扩展开关可独立启停

核心层

  • Qlib 集成适配（qlib_core_integration.py）—— 信号归一化、绩效指标计算、回测配置归一化、mlflow 可用性探测
  • 数据路径探测（qlib_paths.py）—— 自动定位本机真实 qlib 数据目录并三重校验（calendars/ + features/ + instruments/）
  • 实验记录与降级（qlib_exp_shim.py）—— mlflow 缺失时用空实现兜底，链路照样跑通

引擎层

  • 内置 qlib 源码 + 回测越界补丁（patches/apply_qlib_patches.py 幂等固化，启动时自动检查）

质量保障

  • 核心纯净性守门测试（tests/test_core_purity.py）—— AST 静态分析核心模块的模块级导入闭包，防止扩展依赖反向渗入
  • 工作流校验 —— 节点类型／属性合法性／端口存在与方向／环检测／孤立节点（警告级）

七、设计原则

  1. 配置只有一个生效入口 —— 节点属性编辑器。曾经存在「管理界面配了、节点却不读」的配置孤岛，已全部删除
  2. 依赖单向 —— 核心不 import 任何扩展，由守门测试锁死边界，防止以后回退
  3. 第三方库路径放末尾 —— 避免同名包遮蔽（本项目先后踩过 core 与 nodes 两次）
  4. 补丁必须可重复执行 —— 幂等；源码不匹配时明确报错而非静默跳过
  5. 宁可失败也不造假 —— 拿不到真实预测就明确报错，绝不生成随机信号让回测跑出无意义结果

九、下一步方向

LLM 驱动建模 —— 让工作流从「手动画图」变成「描述需求即可生成」。这是目前唯一有实质缺口的方向。

环节现状
LLM 接口已具备（支持 OpenAI / Claude / Ollama / 自定义）
本地模型已具备（约 42 GB：deepseek-r1 / qwen3.5 / qwen3-vl + 3 个 embedding）
知识库 + 向量检索已具备
节点图序列化与校验已完成（第 1 步）
LLM 输出 → 可执行节点图待实现（第 2 步）；节点说明书已生成
生成结果校验与预览确认待实现（第 3 步）
前置条件：需启动 Ollama 服务，或在 GPUStack 上部署一个模型（服务连通、密钥有效，但当前未部署模型）。
三条原则：不做孤岛（生成结果必须能真跑通）· 必须有校验（LLM 输出不可信）· 可回滚（生成结果只作预览，用户确认后才落到画布）。
